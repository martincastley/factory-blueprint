# Factory Blueprint

A blueprint-style production planner for Satisfactory.

**Live app:** https://martincastley.github.io/factory-blueprint/ (in Chrome or Edge, click the install icon in the address bar to use it as a desktop app)

- Wizard: products → recipes → resources (nodes, purity, miners, belts) → priority → optimization goal
- Solver: 100 % efficiency mode (no idle machines), max output, fewest buildings, lowest power
- To-scale manifold layout on the 8 m foundation grid, with automatic splitting of overloaded belts
- Zoom, pan, drag and rotate buildings; belts follow

Recipe data: Satisfactory 1.0, from the open-source [SatisfactoryTools](https://github.com/greeny/SatisfactoryTools) project.
